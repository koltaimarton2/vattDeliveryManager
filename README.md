# Vatt - Ételkiszállító és Logisztikai Panel

Egy egyszerű, TypeScript-alapú webes alkalmazás, amely a győri ételkiszállítási logisztikát koordinálja és szimulálja. A rendszer segítségével nyomon követhetők a várakozó rendelések, az aktív kiszállítások és a futárok aktuális státuszai.

## Főbb funkciók
- **Rendeléskezelő Panel:** Új rendelések felvétele kliensoldali validációval, valamint kézi futár-kiosztás.
- **Automatikus kiosztás (Auto-Assign):** A várakozó csomagok automatikus párosítása a szabad (idle) futárokkal.
- **Folyamatkövetés:** Valós idejű szállítás-szimuláció progress bar animációval a folyamatban lévő rendeléseknél.
- **Futárkezelés:** Új futárok regisztrációja, járműtípusok és nyelvismeret beállítása, valamint státuszváltás (online/offline).
